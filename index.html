What is this?

A respring restarts the device's interface shell. The screen goes dark for a couple of seconds and the UI comes back up — faster than a full reboot, because only the shell restarts, not the whole system.

A Web Respring does it straight from the browser: no tweaks and no extra apps to install. It is all handled by the page neonmodder123 built.

NeoRespring is a comfortable shell around that page: it installs to your home screen like a normal app, opens offline, and fires the Respring from one big button. The Respring itself is done by neonmodder123's page — all credit goes there.
